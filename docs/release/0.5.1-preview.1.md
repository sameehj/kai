# Kai 0.5.1-preview.1 (pre-release)

The public preview. Identify a build by its commit: `kai version` prints it.

## What changed

- **Internet stays Watch only.** Settings → Internet has one control, **Off · Watch**; the subtitle and the status badge follow the state (teal when watching is fine, amber only when macOS needs you). Telemetry rows say what is true: "Kai turned on Claude Code's own telemetry opt-out." The allowed-destinations list moved to Settings → Advanced → Internet as **Never block these**.
  - "Watch + block my list" (refuse agents' connections to sites you choose) is in the engine and its tests, but **hidden in this release**: it wasn't verified on a real Mac before release. Kai blocks no connections in 0.5.1.
- **Kai is the subject of every stop:** "Kai stopped Claude Code's command", "Kai stopped Claude Code reading .env", "Kai stopped Cursor's connection to paste.example.org", in the popover, Now, Activity, Ask and notifications.
- **Card counts match Activity.** A Now card counts the whole session; when recording started later it adds a muted line ("Recorded in Activity since 16:17: 4 file actions, 12 commands."). Activity's group headers show the same numbers. **Open →** always lands on the All filter.
- **Popover numbers.** "Today: 312 actions · 5 stops · 14 connections" (stops amber above 0; connections only while Internet is on). Each session row: "Ran a command · 6 min ago · 261 commands · 5 stops". The latest stop: "Kai stopped Claude Code's command · 1h".
- **Health line.** "Connected · hooks OK" at rest; "Checking hooks…" only while a check runs; "Claude Code's hooks need repair" in amber with **Repair**.
- **Activity rows.** Paths relative to the session's project; outside it "outside project" and the file name (the full path only in the detail sheet); temporary and scratch files grouped ("tmp · 3 files"). Plain labels: Agent asked to read / write / run, Seen, Stopped; each keeps its evidence level in the sheet.
- **Session cards.** Zero counts are hidden; "Just started" replaces "No command recorded yet"; nested sessions and background services sit under their parent with a short explanation.
- **Ask about this** opens a new chat titled after the item, starting with it quoted. It never goes into the current chat.
- **Codex icon fixed.** The bundled OpenAI mark has light and dark variants; drawn as a plain image, the black mark landed on the dark tile and showed a blank grey square. Bundled marks are now drawn for the current appearance.
- **The stop's decision sheet** names what was stopped with Kai as the subject and adds **Not right**.
- **README pictures** come from `make screenshots`: the real views and a fixture data set, light and dark.

## Engine

- New egress mode `blocklist` (`egress blocklist`), engine only in this release (the app doesn't offer it); `egress_block <host|ip|cidr>[:port]` lines share the `egress_allow` parser. The block list wins over `egress_allow`. Only agent-attributed flows are affected.
- `kai status --json` adds `internet: {mode, enforcing, blocked_sites}`; `kai status` says "Watch + block my list: refuses agents' direct connections to N listed sites; records the rest".
- `kai activity --json` adds `today` (records since local midnight), for the popover.
- Tests: block list parsing, subdomains, IP and CIDR, block wins over allow, non-agent flows unaffected, a release-build test (`blocklist` effective, strict `block` clamped to `log`), and app tests for the words, counts, paths and logos.

## Not changed

Evidence levels (requested / tool-reported / confirmed / unknown). No model in the decision path. Storage Wall and Network Wall enforcement in the app (Watch only). Private keys can't be allowed from the app. Recording stays on by default, metadata only, kept 7 days.

## Known limits

- Internet observes connections and blocks nothing in this release.
- The model runs inside the Kai app process.
