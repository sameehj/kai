# S4 — Session-scoped permissions and override tiers (live test)

Grants already match on session id + resource + operation and refuse agent-tree
creators (M1). S4 adds the **override tiers** and their enforcement.

## What changed

- **Tier taxonomy** (`kai_override_tier`, `src/scan.c`): control store → NEVER;
  a private key / cloud credential rule → BREAK-GLASS; the trust store →
  OVERRIDE; other protected paths / blocked hosts → CONFIRM.
- **Signed honor flags** (grant v3, `src/grant.c`): `confirmed` and
  `authenticated` are part of the signed canonical form, so an agent cannot flip
  them on a signed grant to escalate its tier. New `kai_grant_build_json3`.
- **Enforcement at honor time** (`kai_storage_decide` and the live
  `kai_approval_store_decide`): a matched grant is honored only if it meets the
  tier — `kai_grant_satisfies_tier`:
  - NEVER: never (the control store is already un-grantable).
  - BREAK-GLASS: only a `read`, `authenticated`, TTL ≤ 15 min.
  - OVERRIDE: only if `confirmed`.
  - CONFIRM/normal: as before.
- **Session-end expiry**: a session-bound grant is dropped at the next grant-store
  reload once the registry shows its session ended (`kai_grant_session_ended`,
  applied in the reload cleanup — off the ES hot path, so decide() does no file
  I/O). `kai_storage_decide` (CLI path) checks it inline.
- **App** (`Approvals.swift`): `approve` signs v3 grants; break-glass requires
  **LocalAuthentication** (Touch ID / login password) and then signs a
  read-only grant capped at 15 min; never-tier is not approvable. The grant
  signer remains the only path that signs, in a Kai-owned window.

## Automated tests — PASS (`make test`, exit 0)

`run_storage_tests` → `test_grant_tiers`: override tier honored only when
confirmed; break-glass honored only with auth + read + short TTL (write never,
long TTL never); never-tier (control store) never honored; a session grant is
honored while active and denied after `kai_session_end`; an unattributed process
never matches a session-bound grant. (The existing agent-cannot-create-a-grant
and session-A-not-B matching stay covered by the grant tests.)

   tier). The decision card offers "Override for this session"; after the confirm

   confirm-tier file, then quit the agent. Within the reload bound, that grant is
   gone (audit shows "expired … session ended"); a new session is denied until
