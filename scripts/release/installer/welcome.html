Kai Preview: give AI more work, not more access.

Kai Preview checks supported actions inside Claude Code, Codex and Cursor before they run. It is an extra safety layer, not isolation or OS-level enforcement: hooks run with your permissions, cover only the actions each agent reports to them, and a program the agent runs can get around them. Codex runs hooks only after you trust them.

Kai Preview checks inside your agents. OS-level protection for files and internet comes with the Kai app in an upcoming release.

  1. Install Kai. This package installs the kai command and adds Kai's checks to the agents that already use them. Run kai install afterwards for any other agent.
  2. Kai checks your agents and stops unwanted moves before they run: reading your keys, sending files out, secrets in prompts. Each stop says what happened, why it matters, and what you can do.
  3. You decide what they can do, narrowly. When Kai stops something legitimate, its message gives the exact command to run in your own terminal, for one agent, one operation, one target, with an expiry.

After installing: kai demo shows the checks working with a fake secret, and kai status shows what is checked for each agent.
