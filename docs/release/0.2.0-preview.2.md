# Kai 0.2.0 Preview 2

**Turn off your agent's permission prompts. Kai stops it reading your secrets or sending data where it shouldn't.**

macOS 13 or later; Linux and Windows aren't supported. Claude Code, Codex and Cursor.

**Internet: Kai shows every connection your agents make. Blocking arrives in the next release.**

## What Kai stops

- **Your agent's own secret reads and uploads**: Claude Code, Codex and Cursor reading your keys, `.env` files and
  credentials, or sending them out, stopped before the tool call runs.

What each agent reports, and with what evidence: [COVERAGE.md](https://github.com/sameehj/kai/blob/master/docs/COVERAGE.md).
In short: Claude Code (file reads and writes, shell commands, submitted prompts, MCP tools, web fetches); Codex
(shell commands, submitted prompts, MCP tools, after you trust Kai's hooks in Codex); Cursor (file reads, shell
commands, submitted prompts, MCP tool arguments for secrets).

## What Kai shows

- **Every connection your agents make** (Internet wall, Watch): the host, the agent, and when, including unknown
  hosts, bare IPs and odd ports. Nothing is blocked in this release. Encrypted request contents aren't inspected.

## What it doesn't stop in this release

- Files read or written by scripts the agent writes.
- Planted SSH keys or login items.
- Untagged editors such as VS Code.
- Exfiltration through allowed services like GitHub or npm (`npm publish` included).
- Agent traffic to unknown hosts, bare IPs or odd ports: shown, not blocked. Blocking arrives in the next release.

**Files protection: not included in this release.**

## Install

1. Download `Kai-Preview-0.2.0-preview.2.pkg` and `SHA256SUMS`, then check them:
   ```sh
   shasum -a 256 -c SHA256SUMS
   spctl --assess --type install -vv Kai-Preview-0.2.0-preview.2.pkg   # "source=Notarized Developer ID"
   ```
2. Open the package. It installs `/Applications/Kai.app` (with its Internet wall) and `/usr/local/bin/kai`, and
   refreshes Kai's checks in agents that already have them.
3. Open Kai and approve the Internet wall when macOS asks (System Settings → Privacy & Security, or General → Login
   Items & Extensions → Network Extensions).
4. `kai install all`, then `kai doctor` and `kai status`. Codex: run `/hooks` in Codex and trust Kai's.

## Uninstall

1. `kai uninstall all` removes Kai's hooks (`--purge` also removes `~/.kai`: policy, log, permissions). Hooks go
   first, so no agent calls a missing `kai`.
2. Quit Kai and drag `/Applications/Kai.app` to the Trash; macOS removes the Internet wall with it.
3. `sudo rm -f /usr/local/bin/kai; sudo rm -rf /usr/local/share/kai; sudo pkgutil --forget io.github.sameehj.kai.preview`

## Why Watch only

([FRICTION-POSTMORTEM.md](https://github.com/sameehj/kai/blob/master/docs/security/FRICTION-POSTMORTEM.md)). Blocking
returns when it can't strand an agent: the next release's Guard, held to the replay cases in the plan.
