What this installer does

  • Installs /usr/local/bin/kai (Universal, macOS 13 or later) and Kai's default policy.
  • For the person signed in: removes an earlier Kai's Chrome helper, and refreshes Kai's hooks in Claude Code, Codex and Cursor only where Kai's hooks are already installed. Each settings file keeps your original as .kai-bak and the previous state as .kai-bak.prev. What changed is written to /var/log/install.log.
  • Refuses to install over a newer Kai.

What Kai Preview doesn't do

  • No OS-level enforcement: no Files or Internet protection in this preview.
  • It checks only actions an agent reports to its hooks: see what's checked, per agent, in docs/COVERAGE.md or with kai status.
  • A program with your permissions can change Kai's rules and policy. Kai notices some outside policy changes (kai doctor), not all, and prevents none.

Remove it

kai uninstall all removes Kai's hooks; kai uninstall all --purge also removes Kai's settings and log.
