# Kai 0.3.0-preview.1 (pre-release)

A hook-focused preview for the developer study: Kai checks less, explains more, and never stops your agent when it breaks. Identify a build by its commit: `kai version` prints it.

## What changed

- **Kai leaves routine work to your agent.**
  - Ordinary MCP tools get no Kai decision and are recorded, so your agent's "don't ask again" holds.
  - Kai asks only before destructive MCP tools and MCP calls that send to a host other than the server's own.
  - An MCP approval now holds until you undo it.
- **A broken Kai never stops your agent.**
  - If Kai's program is missing, your agent keeps working, and Kai says its checks are off and its settings aren't protected.
  - Repair in the app puts back the program and the hook launcher with one admin prompt.
- **New stops:** printing a saved token or password (`gh auth token`, `git credential fill`, `security … -w`), and writes that reach Kai's or the agents' settings through a symlinked folder.
- **Fewer false stops.**
  - A path named in a commit or PR message, a search pattern, or a file body written with `cat`/`tee` is no longer treated as an access.
  - Reading a test file that holds only Kai's canonical fake tokens is allowed.
- **Cursor:** when Kai has no objection it now gives no opinion, so Cursor's own approval always decides.
- **App:**
  - status words: Checking, Partly checking, Not checking, or red when Kai is broken;
  - one popover order, with a coverage screen;
  - a Why sheet with "Retry would now be" and **Not right**;
  - a Copy button on stop cards;
  - one notification per incident;
  - Settings → **Uninstall**, which removes and checks each piece and lists what's left.
- **Internet (preview) is off by default.** When you switch it on it only watches; nothing is blocked. There are no per-host cards.
- **New commands:** `kai why <id> [--json]`, `kai not-right <id>`, `kai stats --export`.

## Limitations

- **Scripts and subprocesses aren't checked.** Kai sees `python3 script.py`, not what the script opens or sends. The same goes for anything a subprocess does on its own.
- **Editor extensions** (VS Code and Cursor extensions) aren't checked.
- **Network is watch-only.** The Internet wall, when on, records connections and blocks nothing. It sees destinations, never contents.
- **Cursor:**
  - file writes aren't reported to hooks;
  - MCP calls get the secret scan only (no destructive or other-host asks);
  - Kai's no-opinion reply was checked against Cursor 3.27.22's code, not yet in a live session.
- **MCP approvals aren't re-checked** when the server's program or tools change.
- **No Files wall** in this release.

Full list, with every case Kai is tested against: `docs/ESCAPES.md`. Coverage per agent: `docs/COVERAGE.md`.

## Install and verify

Install the signed `.pkg` from the release page and check its SHA-256 against the value listed with it. Then:

```
kai version
kai install claude
kai install cursor
kai doctor
```

Uninstall: Kai → Settings → Uninstall.
