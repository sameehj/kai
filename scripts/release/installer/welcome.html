Kai Preview

Turn off your agent’s permission prompts. Kai stops it reading your secrets or sending data where it shouldn’t.

What Kai stops

  • Your agent's own secret reads and uploads: Claude Code, Codex and Cursor reading your keys, .env files and credentials, or sending them out, stopped before the tool call runs.

Internet: Kai shows every connection your agents make. Blocking arrives in the next release.

What it doesn’t stop in this release

  • Files read or written by scripts the agent writes.
  • Planted SSH keys or login items.
  • Untagged editors such as VS Code.
  • Exfiltration through allowed services like GitHub or npm.
  • Agent traffic to unknown hosts, bare IPs or odd ports: the Internet wall shows it and blocks nothing in this release.

Files protection: not included in this release.

  1. Install Kai. This package installs the Kai app (with its Internet wall) and the kai command, and refreshes Kai's checks in the agents that already use them.
  2. Approve the Internet wall when macOS asks, then run kai install all and kai doctor.
  3. Kai checks your agents and stops unwanted moves before they run: reading your keys, sending files out, secrets in prompts. Each stop says what happened, why it matters, and what you can do.
  4. You decide what they can do, narrowly. When Kai stops something legitimate, its message gives the exact command to run in your own terminal, for one agent, one operation, one target, with an expiry.

After installing: kai demo shows the checks working with a fake secret, and kai status shows what is checked for each agent.
