# Commercial licensing

Kai is published under the GNU General Public License v3 (GPLv3). That license
is a good fit for most users: you can run Kai, read its source, change it, and
share it.

GPLv3 has one requirement that some companies cannot accept: if you distribute a
product that **includes or links Kai's code**, you must release the source of
that product under GPLv3 too. If you want to embed Kai's engine (`libkai`, the
C API in `include/kai.h`) inside a **closed-source** product — an IDE, an agent,
a security tool, an appliance — you need a commercial license instead.

A commercial license gives you:

- The right to embed `libkai` in a proprietary product with no copyleft
  obligation.
- Priority support and security advisories.
- Help with integration and, where relevant, evidence for your own compliance
  and certification needs.

This is the same dual-licensing model used by projects like wolfSSL.

**You do NOT need a commercial license to:**

- Use Kai on your own machines, at home or at work.
- Run it across your company's laptops.
- Modify it internally.
- Contribute changes back.

**You DO need one to:**

- Ship Kai's code inside a closed-source product you distribute.

To discuss a commercial license, contact **licensing@<domain>** (placeholder —
set this before launch).

Because every contribution is covered by the [CLA](CLA.md), the project holds the
rights needed to offer these commercial terms.
