# Quickstart

1. Build:

```bash
make build
```

2. First run (wizard):

```bash
./bin/kai
```

3. Probe target:

```bash
./bin/kai probe --target local
```

4. Single-shot diagnose:

```bash
./bin/kai --target local -c "my server is slow"
```

5. Start gateway:

```bash
./bin/kai gateway start
```
