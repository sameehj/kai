# S7 — Permission manager and history (live test)

A **Permissions** page in Settings: every active grant across sessions and
projects, plus the recent lifecycle history, with Revoke.

## What changed

- `SettingsView.swift` → new `PermissionsPage` (SettingsPage `.permissions`,
  key icon):
  - **Active grants**: from `GrantManager.grantGroups` (identical grants
    collapsed with a count), each showing agent · op · scope, resource,
    countdown/status, and **Revoke / Revoke all**.
  - **Recent history**: `model.events` filtered to `source == "grant"` —
    requested / approved / used / expired / revoked — with a filter (All /
    Granted / Used / Ended) and relative times.
- Revocation propagation and lifecycle auditing are the existing engine
  behaviour: `revoke` deletes the grant file; the approval store's reload
  cleanup drops revoked/expired/session-ended grants from BOTH walls' snapshot
  (within the reload bound) and audits each (`kai_grant_audit`
  requested/approved/used/expired/revoked, with agent, resource, op and reason).

## Automated tests — PASS (`make test`, exit 0)

The lifecycle auditing and revoke-reaches-the-walls behaviour are covered by
`run_storage_tests` → `test_approval_store` (expiry/bad-signature/revocation are
audited; the reload drops them so neither wall honors them afterward) and by
`test_grant_tiers` (session-end expiry). The page itself is SwiftUI (no Swift
test target); its filter/grouping is reused from the tested `grantGroups`.
